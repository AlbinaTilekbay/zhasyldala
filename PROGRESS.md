# PROGRESS — ZhasylDala

Журнал работ по проекту. Обновлять после каждой значимой сессии.
Последнее обновление: 2026-10-19.

## Текущее состояние

- Приложение задеплоено на Railway (`Dockerfile.railway`, один образ:
  gunicorn отдаёт и React, и API, и админку), репозиторий
  `github.com/albinatilekbay/zhasyldala`, ветка `main`.
- Основной движок диагностики — OpenAI `gpt-4o` (vision); офлайн-резерв —
  MobileNetV3, обученный на PlantVillage (томат, перец, клубника).
- Оба сценария работают: теплица фермера (QR-секторы + фото) и домашнее
  растение без регистрации.
- Подготовлена шпаргалка к защите — `ZAWITA_PROEKTA.md`.

## Известные несоответствия / техдолг

- `makemigrations --check` показывает несозданную миграцию
  `accounts.User.groups` (из-за версии Django, не из-за кода проекта).

- `README.md` местами всё ещё пишет `gpt-4o-mini`, а в коде `gpt-4o`.
- `docker-compose.yml` передаёт `PLANTNET_API_KEY` (удалённый сервис) и не
  передаёт `OPENAI_API_KEY` — в Docker Compose OpenAI-режим не включится.
- В `README.md` есть раздел «this was written, not run» — устарел, проект
  уже запущен и задеплоен.
- Нет тестов для пошагового скана и эндпоинтов обучения в админке.
- Регистрация без SMS-подтверждения.
- Фронтенд везде берёт «первую теплицу» — нет переключателя для
  нескольких теплиц (бэкенд уже поддерживает).

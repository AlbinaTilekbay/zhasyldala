## Известные несоответствия / техдолг

- `README.md` местами всё ещё пишет `gpt-4o-mini`, а в коде `gpt-4o`.
- `docker-compose.yml` передаёт `PLANTNET_API_KEY` (удалённый сервис) и не
  передаёт `OPENAI_API_KEY` — в Docker Compose OpenAI-режим не включится.
- В `README.md` есть раздел «this was written, not run» — устарел, проект
  уже запущен и задеплоен.
- PDF-лист секторов (`qr_sheet_pdf`) рисует кириллицу шрифтом Helvetica —
  казахские подписи там, скорее всего, отображаются квадратами.
- Нет тестов для пошагового скана и эндпоинтов обучения в админке.
- Регистрация без SMS-подтверждения.
- Фронтенд везде берёт «первую теплицу» — нет переключателя для
  нескольких теплиц (бэкенд уже поддерживает).
